      Usage

      One icon set, every platform.

      The same icons, names, and motions everywhere: a Web Component on the web, typed components for each framework, and a native renderer for React Native.

      Ship only the icons you use

      The default import registers every icon, so any name just works. For production apps, import the element and just the icons you need: bundlers drop everything else.

      Framework packages have the same split: @lumi-icons/react/lean, /vue/lean, /angular/lean, /react-native/lean, plus an icon prop.

      import { registerIcons } from "@lumi-icons/core/element";
import { rocketIcon, heartIcon } from "@lumi-icons/core/icons";

registerIcons(rocketIcon, heartIcon);

// <lumi-icon name="rocket"></lumi-icon> now works,
// and only these two icons are in your bundle.
